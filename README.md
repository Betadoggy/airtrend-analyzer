# 미래 공항산업 트랜드 키워드 분석 (인천공항 ver)
main.py를 실행

폴란드어 기사 1개 제외

논문 참고문헌 목록 제외

블랙핑크 제니 관련 인천공항과 관련없는 기사 -> 필터링 고도화(반드시 인천공항이 들어간 본문 내용만 분석하도록)

인명 관련 : 제니, 트레비스 킹, 정국

불용어 : VNA (베트남 언론사)
